Image to PIC

Converts a PNG, JPG, or GIF into three 1-bit RGB bitplanes.

Choose a PNG, JPG, or GIF up to 640 × 200 pixels.

Dither the image first at ditherit.com.

PIC output preview

Header format: 2 bytes for width followed by 2 bytes for height, both unsigned 16-bit little-endian. The data is packed into bytes per row, in blue, green, red order.
